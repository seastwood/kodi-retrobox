# Add-ons registered as disabled rather than enabled.
#
# EMPTY ON PURPOSE. Kodi asks "Would you like to enable this add-on?" about a
# DISABLED add-on that something still references -- so switching one off is
# what causes the prompt, not what prevents it. Disabling the spectrum
# visualiser produced exactly the dialog it was meant to remove.
#
# Everything Kodi ships is therefore registered enabled, which is also what the
# original machine does and what never prompts there. visualization.spectrum is
# a music visualiser and a Recommends of the kodi package: unused by a games
# console, harmless, and about 100 KB.
#
# To genuinely switch something off, disable it here AND remove whatever refers
# to it (for the visualiser, set Settings > Player > Music > Visualisation to
# None), or the dialog comes back.
