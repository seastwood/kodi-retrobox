# Everything this console needs, derived from what the code actually calls
# rather than from a dump of installed packages. `apt-mark showmanual` on the
# live machine lists 1878 packages because it includes the whole Mint desktop;
# this is the part that matters.

# Emulation
retroarch
retroarch-assets
retroarch-data
libretro-core-info

# Front end
kodi
kodi-eventclients-kodi-send
kodi-peripheral-joystick
kodi-inputstream-adaptive

# The player picker, the hold-to-exit overlay and the icon drawing
python3-pygame
python3-evdev
python3-pil

# Screen, window and input plumbing the launcher drives
x11-xserver-utils
wmctrl
xdotool
scrot
libnotify-bin
onboard

# Bluetooth pairing (script.bluetooth)
bluez

# USB over IP (script.usbip); usbip lives in linux-tools.
# These two are not enough on their own: linux-tools-common ships only a
# wrapper script and linux-tools-generic tracks the GA kernel, so the binary
# for the kernel you booted may still be missing. install.sh adds
# linux-tools-$(uname -r) as well, and bin/usbip-setup-root.sh checks it.
linux-tools-common
linux-tools-generic

# Housekeeping: backups, the repo itself, downloading cores and art
rsync
git
curl
unzip

# How the Moonlight add-on installs Moonlight. This repository installs that
# add-on, so this repository is what has to make sure the thing it needs is
# here: on a machine without flatpak the MOONLIGHT entry can only say it
# cannot do anything, which is a menu row that does not work on a console
# somebody has just built. Mint ships it, Ubuntu does not always, and neither
# is a thing to depend on.
flatpak
# x264enc lives here, and nothing else provides it. A Mint desktop
# installs the "bad" set and not this one, so without it a machine
# encodes H.265 and reports that it cannot do H.264 -- which is the one
# every browser takes.
gstreamer1.0-plugins-ugly

# Hardware video encoding, for whatever GPU the machine turns out to have.
# Fourth Player encodes the screen once for every guest, and doing that on the
# CPU is not merely slower: 1080p in software took one of these machines to
# load average fifty and held it there, with no ssh, until somebody reached
# the power button.
#
# va-driver-all pulls the right VA-API driver for the card that is present --
# mesa for AMD, intel-media or i965 for Intel -- so this does not have to know
# which one it is. plugins-bad is where the vah264enc and nvh264enc elements
# live. vainfo is how you find out what a strange machine can actually do.
va-driver-all
gstreamer1.0-plugins-bad
vainfo
