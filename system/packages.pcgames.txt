# Everything the PC-games side needs, installed by install.sh --with-optional.
#
# Wine runs the Windows games; JoyShockMapper turns a controller into keyboard
# and mouse for games that have no pad support, and is built from source
# because the Linux port needs patches (system/joyshockmapper/).

# Wine, from the WineHQ repository install.sh adds
winehq-staging
winetricks

# Building JoyShockMapper
cmake
make
# clang, not g++: JoyShockMapper specialises templates inside a class, which
# GCC 13 rejects outright and clang accepts. The original build used clang and
# nothing recorded that except a CMake cache.
clang
g++
pkg-config
libgtk-3-dev
libayatana-appindicator3-dev
libevdev-dev
# JoyShockLibrary, which JoyShockMapper pulls in during its build, needs this
# and says so only once cmake is already running.
libhidapi-dev
