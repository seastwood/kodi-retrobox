BIOS files go in this folder.

Some systems cannot run without one: Sega CD, Saturn, Dreamcast, PlayStation,
PC Engine CD, 3DO, Atari Lynx and a few others. Supply your own dumps and put
them here with the exact names the cores expect -- the full list is in
system/bios-required.txt in the repository.

Do NOT put them in ~/Games/emulation/. A BIOS sitting in a ROM folder looks
exactly like a game, and the sync deliberately drops it from the playlist.

If a game will not start, the launcher shows the reason on the television and
names the file it wanted, for example:

    Missing BIOS file: bios_CD_U.bin

That message is the authority. This folder is where the answer goes.
